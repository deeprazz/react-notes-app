# Notes App (React + Vite)

A simple notes application built using **React** and **Tailwind CSS**.
Users can write notes and view them in a clean card layout.

## Features

- Add notes with a heading and details
- Clean UI with Tailwind CSS
- Responsive layout
- Form submission handling

## Tech Stack

- React
- Vite
- Tailwind CSS
- JavaScript

## Installation

Clone the repository

```
git clone https://github.com/your-username/notes-app.git
```

Go to the project folder

```
cd notes-app
```

Install dependencies

```
npm install
```

Run the development server

```
npm run dev
```

## Usage

1. Enter the **note heading**
2. Write the **note details**
3. Click **Add Notes**

Your notes will appear on the right side.
